# Mezovest Limited

## About the company
- An IT first energy and finance company, one of Nigeria's big names in the LPG and CNG business.

## What he built
- Led the re-engineering of a legacy fintech monolith into TypeScript and Python microservices.
- Designed distributed backend services on RabbitMQ for asynchronous processing of financial transactions and reporting workflows.
- Containerized and deployed services with Docker and Kubernetes for consistency and scale across environments.
- Implemented CI/CD workflows with GitHub Actions, cutting about 20 minutes from each deployment.
- Built secure backend services with role-based access control for internal supply-management applications.
- Built a Go file repository service backed by Amazon S3 for organized, secure file storage and sharing with stakeholders.
- Took part in architecture decisions, code reviews, debugging and technical problem-solving across the development lifecycle.

## Results
- The microservices re-architecture improved system efficiency by about 100% (roughly twice as efficient).
- Deployments became about 20 minutes faster with less release complexity.

## Stack
- TypeScript, Python, Go, RabbitMQ, Docker, Kubernetes, PostgreSQL, GitHub Actions, AWS S3.
